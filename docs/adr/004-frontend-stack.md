# ADR-004 控制台使用本地网页，前端使用 Vite、React 和 TypeScript

## 状态

已接受。

## 背景

控制台包含向导、密钥管理、工作舱列表、拦截卡片、出舱审查和会话报告等页面。项目规则禁止引入需要 CGO 的依赖。Airlock 只发布一个可执行文件。

## 决策

- 控制台是本地网页。`airlock.exe` 内嵌前端文件，启动后在浏览器中打开控制台。
- 控制台只监听 `127.0.0.1`，每个请求都要带启动时生成的随机令牌。
- 前端使用 Vite、React 和 TypeScript。
- 新增前端依赖前，用 `npm view <包>` 核实，锁定版本，并提交 `package-lock.json`。

## 备选方案

| 方案 | 不选的原因 |
|---|---|
| Wails 桌面程序 | 团队要额外学习一个桌面框架。本地网页只需要 Go 的 HTTP 服务，风险更小。 |
| Electron 桌面程序 | 安装包大。需要单独维护一个 Node.js 主进程。 |
| 不用框架的原生 HTML | 页面多、状态多，手写更新逻辑的工作量大。 |

## 后果

- 好处：只发布一个可执行文件。CI 可以对前端做类型检查和构建。
- 坏处：用户在浏览器中使用控制台，没有系统托盘图标。
- 控制台必须防御本机恶意网页的请求，见 [security.md](../security.md#5-威胁与防护措施) 中的 T-12。
